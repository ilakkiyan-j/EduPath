# EduPath AI — Database Schema & Data Models

## 1. ORM & Storage Architecture
- **ORM**: Prisma ORM with typed client.
- **Provider**: PostgreSQL / SQLite (dual-compatible for zero-friction local development and cloud production).
- **Vector Search Support**: `pgvector` compatible schema for future semantic resource retrieval.

---

## 2. Core Entity Relationship Models

## 3. Entity Definitions

1. **User**: Unique ID, email, name, avatar, role, created/updated timestamps.
2. **LearnerProfile**: Links to User, experience level, summary, target role ID, career readiness score (0-100).
3. **Role**: Title (AI Engineer, etc.), slug, description, minimum required experience.
4. **Skill**: Name, category, description, difficulty rating.
5. **RoleSkill**: Pivot linking Role to Skill with required proficiency level (1-5) and importance.
6. **SkillDependency**: Directed graph edge linking prerequisite skill to target skill.
7. **LearnerSkill**: Learner's current assessed level (1-5), confidence score (0.0-1.0), status.
8. **SkillEvidence**: Text snippets extracted from resume/evaluations validating a skill rating.
9. **SkillGap**: Quantified deficiency between current level and role required level, classified by gap severity (`acquired`, `developing`, `moderate`, `high`, `critical`).
10. **Roadmap**: Active generated learning journey with total estimated weeks and weekly hour commitments.
11. **RoadmapItem**: Milestone entry with week number, title, description, skills addressed, and status (`pending`, `in_progress`, `completed`, `adapted`).
12. **RoadmapAdaptation**: Historic audit log of mutations made to the roadmap with triggers, before/after diffs, and evidence justifications.
13. **LearningResource**: Curated learning material with type, URL, estimated duration, and tailored rationale.
14. **Task**: Practice challenge with requirements, starter code, test rubric, and addressed skills.
15. **TaskSubmission**: Learner's submitted code, text, or GitHub URL.
16. **TaskEvaluation**: Structured scorecard generated by `EvaluationAgent` with overall score, demonstrated skills, identified weaknesses, and feedback items.
17. **LearnerMemory**: Long-term state store recording persistent strengths, repeated struggle areas, completed topics, and learning style patterns.
18. **AgentEvent**: Chronological log entry recording every agent action, thought, decision, and evidence for the transparent activity timeline.
19. **GeneratedProject**: Cross-cutting capstone projects synthesized by AI to close multiple skill gaps simultaneously.
